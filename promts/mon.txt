Je développe une plateforme web de laboratoire de chimie virtuel appelée **ChemLab**. Je souhaite améliorer la barre de navigation (Navbar) afin d’obtenir un design **professionnel, moderne, élégant, responsive et animé**, adapté à une plateforme scientifique.

### Objectif
Créer une Navbar de qualité professionnelle qui donne immédiatement une impression de sérieux, d’innovation et de modernité.

### Structure de la Navbar
La Navbar doit contenir :

- À gauche : le **logo ChemLab** avec une petite icône représentant la chimie ou un laboratoire.
- Au centre ou à côté du logo, les liens :
  - **Accueil**
  - **Laboratoire**
  - **Catalogue**
  - **Expériences**
  - **Groupes**
  - **À propos**
- À droite :
  - une icône de recherche
  - un bouton **Se connecter**
  - un bouton principal **Créer un compte**
  - éventuellement une icône de profil lorsque l'utilisateur est connecté.

### Design
Utiliser un style :
- moderne et professionnel ;
- minimaliste mais visuellement attractif ;
- inspiré des plateformes scientifiques et technologiques modernes ;
- avec des coins légèrement arrondis ;
- une bonne hiérarchie visuelle ;
- suffisamment d'espace entre les éléments ;
- une typographie moderne et lisible ;
- une excellente visibilité sur ordinateur, tablette et mobile.

### Animations
Ajouter des animations fluides et discrètes :

1. Lorsque la souris passe sur un lien, le lien change légèrement de couleur et une **ligne animée apparaît sous le lien**.
2. Le logo possède une petite animation au survol.
3. Les boutons ont un effet **hover** avec une transition douce.
4. Ajouter un léger effet de déplacement ou d'ombre lors du survol des boutons.
5. La Navbar doit apparaître avec une animation légère lors du chargement de la page.
6. Lors du défilement de la page, la Navbar devient légèrement plus compacte et ajoute une ombre ou un effet de transparence.
7. Les animations doivent rester professionnelles et ne pas être excessives.

### Navbar au scroll
Lorsque l'utilisateur descend dans la page :
- la Navbar doit rester fixée en haut (`position: sticky` ou `fixed`) ;
- son arrière-plan devient légèrement opaque/translucide ;
- ajouter un effet `backdrop-filter: blur(...)` si possible ;
- ajouter une légère ombre ;
- réduire légèrement sa hauteur avec une transition fluide.

### Responsive Design
Sur mobile :
- remplacer les liens par un **menu hamburger animé** ;
- lorsqu'on clique sur le hamburger, le menu apparaît avec une animation fluide ;
- le bouton hamburger doit se transformer en icône « X » lorsqu'il est ouvert ;
- le menu doit être parfaitement adapté aux écrans mobiles.

### Technologie
Mon projet utilise **Django avec HTML, CSS et JavaScript**.

Je veux donc une solution compatible avec Django et sans framework JavaScript comme React, Vue ou Angular.

Organiser le code proprement en trois fichiers :

- `navbar.html`
- `navbar.css`
- `navbar.js`

Le code doit être :
- propre ;
- commenté ;
- facilement intégrable dans un projet Django ;
- responsive ;
- accessible ;
- sans erreurs JavaScript ;
- sans dépendances inutiles.

### Important
Ne crée pas seulement une maquette visuelle. Fournis une **Navbar réellement fonctionnelle** que je peux intégrer directement dans mon projet Django.

Utilise des animations CSS modernes (`transition`, `transform`, `opacity`, `box-shadow`, `backdrop-filter`, etc.) et du JavaScript uniquement lorsque cela est nécessaire.

Le résultat final doit donner l'impression d'une **plateforme professionnelle de laboratoire scientifique virtuelle**, cohérente avec l'identité visuelle de **ChemLab**.
